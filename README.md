# متجر عطور عزام الشمري الفاخر | صفحة هبوط سريعة بنظام الدفع عند الاستلام (COD) في العراق

مشروع متكامل فائق السرعة والأداء مصمم خصيصاً لحملات إعلانات Meta في العراق بتصميم هادئ وراقٍ مستوحى من أسلوب Apple (Apple-Style Light Design). مبني بالكامل على بيئة **Cloudflare Workers** وقاعدة بيانات **Cloudflare D1**، مع دعم كامل للغة العربية (RTL)، تتبع مضاعف بدون تكرار (**Meta Pixel + Conversions API**)، مزامنة تلقائية مع **Google Sheets**، تخزين صور بالـ D1، حماية ذكية غير مرئية بـ **Cloudflare Turnstile**، ولوحة تحكم متطورة لإدارة الطلبات والمنتجات والمخزون.

---

## 🌟 الميزات الرئيسية

1. **تصميم Apple-Style Light فائق النقاء والسرعة:**
   - واجهة مضيئة ونظيفة (خلفيات بيضاء ورمادية هادئة `#f5f5f7` مع لون أزرق أبل المميز `#0071e3`).
   - خط **IBM Plex Sans Arabic** خفيف وعصري مع تحميل فوري.
   - أرقام لاتينية واضحة في كافة أقسام الموقع ولوحة التحكم (`en-US` formatting).
   - شريط تثبيت سفلي للهاتف (Sticky Bar) بزجاج ضبابي شفاف (`backdrop-filter: blur(20px)`).
   - متوافق مع كافة أحجام الشاشات ابتداءً من 360px مع حركة انسيابية تحترم تفضيلات المستخدم (`prefers-reduced-motion`).

2. **معرض صور Hero دوّار (Image Carousel):**
   - استبدال المعرض القديم بكاروسيل صور متحرك ومرن داخل القسم الأول (Hero).
   - دعم كامل للسحب بالإصبع (Touch Swipe)، أسهم التنقل، نقاط التبديل (Dots)، والتنقل التلقائي كل 4 ثوانٍ مع التوقف عند التفاعل.
   - يدعم الاتجاه العربي RTL بشكل صحيح. عند وجود صورة واحدة فقط تختفي أزرار ونقاط التحكم تلقائياً.

3. **إدارة المنتجات بالكامل من لوحة التحكم (DB-Driven):**
   - جميع نصوص وإعدادات المنتج تدار من لوحة التحكم (الاسم، الجملة التعريفية، الوصف، النوتات العطرية، الأسعار، شروط الضمان، مراجعات العملاء).
   - تخزين صور المنتج كبيانات ثنائية (BLOB) مباشرة في Cloudflare D1 بدون الحاجة لأي خدمات سحابية خارجية مدفوعة.
   - ضغط تلقائي ذكي للصور في المتصفح قبل الرفع وتحويلها إلى WebP بحجم أقصى 1200px وأقل من 400KB.
   - تقديم الصور بسرعة فائقة عبر مسار `/media/:id` مع ترويسات تخزين مؤقت دائمة (`Cache-Control: public, max-age=31536000, immutable`).

4. **مزامنة ذكية مع Google Sheets (عبر Google Apps Script):**
   - مزامنة فورية غير معطلة للعميل (`ctx.waitUntil`) عند إنشاء أي طلب جديد.
   - تحديث حالة الطلب والملاحظات الإدارية في جدول البيانات فور تعديلها.
   - قفل أمان (LockService) لمنع التداخل والتضارب.
   - مهمة مجدولة (Cron Trigger كل 5 دقائق) لإعادة محاولة مزامنة أي طلبات فشلت في الاتصال تلقائياً.
   - أزرار تحكم في اللوحة لاختبار الاتصال وإعادة مزامنة كافة الطلبات السابقة بضغطة زر.

5. **تتبع Meta Pixel + Conversions API (CAPI) مع إلغاء التكرار:**
   - إرسال أحداث المتصفح (`PageView`, `ViewContent`, `AddToCart`, `InitiateCheckout`, `Purchase`) مع معرف حدث فريد `event_id`.
   - إرسال حدث `Purchase` من خادم Cloudflare مع تشفير SHA-256 للمعلومات الشخصية (الهاتف، الاسم، المحافظة، الدولة) وبنفس الـ `event_id`.
   - إلغاء تكرار دقيق بنسبة 100% يمنع احتساب البيع مرتين ويسترجع البيانات المحجوبة بسبب مانعات الإعلانات.

6. **حماية غير مرئية بـ Cloudflare Turnstile:**
   - حماية خفية (Invisible Mode) تعمل تلقائياً دون إظهار مربع تفاعل يزعج العميل، وتطلب التحقق فقط في حال الاشتباه بنشاط روبوتات.
   - نموذج طلب مخصص للعراق: تحويل الأرقام المشرقية، والتحقق الصارم من صحة رقم الهاتف، ومنع الطلبات المكررة خلال 10 دقائق.

7. **لوحة تحكم إدارية حديثة ومقسمة إلى تبويبات (`/admin`):**
   - حماية مشفرة بكلمة مرور مع كوكيز آمنة `HttpOnly` و `SameSite=Strict`.
   - **تبويب الطلبات (📦):** عرض جدول للشاشات الكبيرة وبطاقات مريحة للهواتف، بحث وفلترة سريعة، تحديث الحالات، كتابة الملاحظات، شارة حالة مزامنة Google Sheets، ورابط مراسلة العميل عبر واتساب مباشرة.
   - **تبويب المنتج (🏷️):** تعديل الأسعار، المخزون، الحجم، النوتات (عرض كشرائح Chips)، خصومات الكمية، مراجعات العملاء، ورفع وحذف وإعادة ترتيب الصور.
   - **تبويب الإعدادات (⚙️):** تعديل اسم المتجر، تفعيل أو تعطيل زر واتساب العائم برقم مخصص (معطل افتراضياً)، حالة واتصال Google Sheets.
   - **منطقة الخطر (Danger Zone):** إمكانية مسح جميع طلبات التجربة بضغطة زر مع كتابة عبارة تأكيد إلزامية "حذف الطلبات" وإمكانية إعادة ضبط المخزون قبل الإطلاق.
   - تصدير كامل إلى Excel عبر CSV مدعوم بـ **UTF-8 BOM** يفتح باللغة العربية بوضوح تام.

## 🛠️ متطلبات التشغيل والمتغيرات السرية

### متغيرات البيئة (في `wrangler.toml`):
- `META_PIXEL_ID`: معرف بيكسل فيسبوك (مثال: `"1234567890"`).
- `META_TEST_EVENT_CODE`: كود اختبار الأحداث لـ Test Events في Events Manager (فارغ في الإنتاج).
- `TURNSTILE_SITE_KEY`: المفتاح العام لـ Cloudflare Turnstile (وضع **Invisible**).

### المتغيرات السرية (تُضبط عبر `npx wrangler secret put`):
1. `ADMIN_PASSWORD`: كلمة مرور الدخول للوحة التحكم.
2. `SESSION_SECRET`: مفتاح تشفير عشوائي طويل (32 حرفاً أو أكثر) لجلسات المسؤول.
3. `TURNSTILE_SECRET`: المفتاح السري لـ Cloudflare Turnstile.
4. `META_ACCESS_TOKEN`: رمز الوصول لنظام التحويلات Meta Conversions API.
5. `SHEETS_WEBHOOK_URL`: رابط Web App لسكربت Google Apps Script.
6. `SHEETS_WEBHOOK_TOKEN`: رمز الحماية السري للتحقق بين الموقع وجدول البيانات.

## 📊 إعداد مزامنة Google Sheets (خطوة بخطوة)

1. أنشئ جدول بيانات جديد في Google Sheets وسمّه (مثلاً: `طلبات متجر عطور عزام`).
2. من القائمة العلوية اختر **Extensions** ثم **Apps Script**.
3. احذف الكود الافتراضي والصق محتويات الملف `google-apps-script/Code.gs`.
4. من القائمة الجانبية في Apps Script اختر **Project Settings** (أيقونة الترس).
5. في قسم **Script Properties** اضغط على **Add script property**:
   - الخاصية: `WEBHOOK_TOKEN`
   - القيمة: ضع رمزاً سرياً عشوائياً (مثل: `my_sheets_secret_token_12345`).
6. اضغط على زر **Deploy** بالأعلى ثم **New deployment**:
   - اختر النوع: **Web app**.
   - في خانة **Execute as**: اختر **Me (حسابك الشخصي)**.
   - في خانة **Who has access**: اختر **Anyone**.
7. اضغط **Deploy** وانسخ رابط الـ **Web app URL**.
8. ضع الرابط والرمز في المتغيرات السرية:
   ```bash
   npx wrangler secret put SHEETS_WEBHOOK_URL
   # الصق رابط الـ Web app URL
   npx wrangler secret put SHEETS_WEBHOOK_TOKEN
   # الصق نفس الرمز الذي وضعته في Script Properties
   ```
9. افتح لوحة التحكم `/admin` -> تبويب الإعدادات -> اضغط "اختبار الاتصال" للتأكد من نجاح الربط وظهور صف الرأس في الشيت.

## 🚀 خطوات النشر والإطلاق (Production Checklist)

اتبع هذه الخطوات لإطلاق الموقع رسمياً على حساب Cloudflare الخاص بك:

1. **إنشاء قاعدة بيانات D1 السحابية:**
   ```bash
   npx wrangler d1 create perfume-db
   ```
   انسخ `database_id` الناتج وضعه في ملف `wrangler.toml` في قسم `[[d1_databases]]`.

2. **تطبيق ترحيل الجداول السحابي:**
   ```bash
   npm run migrate:remote
   ```

3. **إنشاء أداة Cloudflare Turnstile:**
   - افتح لوحة تحكم Cloudflare -> Turnstile -> Add Widget.
   - اختر الوضع: **Invisible** حصراً.
   - انسخ الـ Site Key وضعه في `wrangler.toml` في خانة `TURNSTILE_SITE_KEY`.
   - انسخ الـ Secret Key وارفعه بالسر:
     ```bash
     npx wrangler secret put TURNSTILE_SECRET
     ```

4. **إعداد المتغيرات السرية للإنتاج:**
   ```bash
   npx wrangler secret put ADMIN_PASSWORD
   npx wrangler secret put SESSION_SECRET
   npx wrangler secret put META_ACCESS_TOKEN
   npx wrangler secret put SHEETS_WEBHOOK_URL
   npx wrangler secret put SHEETS_WEBHOOK_TOKEN
   ```

5. **نشر المشروع:**
   ```bash
   npm run deploy
   ```

6. **إعداد المنتج قبل إطلاق الإعلانات:**
   - افتح رابط موقعك على مسار `/admin`.
   - سجّل الدخول بكلمة المرور التي حددتها.
   - انتقل إلى تبويب **المنتج**:
     - فعّل خيار "نشط".
     - أدخل الاسم والسعر والوصف والنوتات العطرية والكمية المتاحة في المخزون.
     - ارفع صور العطر (حتى 8 صور، ستضغط تلقائياً).
     - اضغط "حفظ التغييرات".
   - انتقل إلى تبويب **الإعدادات**:
     - اضغط "اختبار الاتصال" للتحقق من مزامنة Google Sheets.
   - انتقل إلى **منطقة الخطر** واكتب "حذف الطلبات" لمسح كافة طلبات التجربة السابقة لتبدأ بعداد مبيعات نظيف.
